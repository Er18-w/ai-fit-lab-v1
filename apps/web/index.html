这一版怎样理解？

  • 产品底座：个人外形档案，让身形、衣橱、穿搭和未来能力共享同一个“我”。
  • 真实交互：本地外形档案、衣物上传、衣橱选择、搭配画布和保存搭配。
  • 辅助能力：穿着效果比较中包含尺码建议，但尺码不是产品中心。
  • 流程模拟：AI 抠图、真人试穿和 Agent 生成。
  • 未来展示：发型、面部、皮肤、身形与体态使用明确标记的模拟数据。

所有模块共享同一个“我”，但用户可以只用衣橱或只用试穿，不需要完成固定流程。
