# 自如 · 移动端完整 Demo 壳

这是“自如”AI 审美与合身助手的纯静态手机网页 Demo。它用完整产品结构表达远期方向，用一条可解释的短袖尺码链路验证核心价值。

## 真实交互

- 本地身体档案与正面照片采集；
- `getUserMedia()` 后置摄像头请求、权限拒绝和无设备提示；
- 相册 / 系统相机文件输入降级；
- iOS 方向传感器显式授权，以及无传感器可跳过路径；
- M～3XL 样例尺码表；
- 基于胸围松量、肩宽差和衣长/身高比例的本地实验计算；
- 缺少胸围时的候选尺码降级；
- HTTPS 环境下的后置相机与系统相册入口。

## Mock / 假数据

- 商品截图 OCR 识别提示；
- 带免费图库真实照片的示例商品与规格数据；
- 衣服、裤子、鞋子组合搭配；
- AI 试穿异步生成状态；
- 发型发色参考照片、风格参考和体态参数情景。

## 本地启动

直接双击 `index.html` 可以查看大部分流程，但浏览器会因安全策略阻止摄像头。建议在本目录启动静态服务器：

```powershell
cd "E:\work buddy\AI工具数据\ChatGPT\比赛项目\apps\web"
python -m http.server 4173
```

然后在本机浏览器打开 `http://localhost:4173`。现代浏览器通常将 `localhost` 视为安全上下文，因此可请求摄像头。

如果没有 Python，也可使用任意静态文件服务器；项目不需要安装 npm 依赖或构建。

## 真机测试与 HTTPS

手机通过局域网访问 `http://电脑局域网IP:4173` 时，这个地址通常不是安全上下文，`getUserMedia()` 和方向传感器可能不可用。真机测试应使用以下任一种方式：

1. 部署到带有效 HTTPS 证书的测试域名；
2. 使用可信的 HTTPS 开发隧道；
3. 配置手机信任的本地开发证书。

在 iPhone Safari 上，方向传感器授权必须由用户点击按钮触发。相机和方向权限彼此独立；方向权限失败不会阻止流程。

## Mock 边界

- 页面不会上传用户选择或拍摄的照片；照片只存在于当前标签页内存中。
- 未填写人工肩峰宽时，页面用身高生成一个明确标注为“演示估算”的数值，只为填充 UI，不代表算法输出。
- 胸围松量阈值和衣长比例均为待校准 Mock 逻辑。
- 试穿适配器只用定时器模拟异步状态，不包含服务地址、访问密钥或第三方调用。

后续集成时，应保持浏览器只调用自有后端；第三方试穿密钥必须保存在服务端，并使用短期签名图片 URL。
