# 自如 · AI 审美与合身助手 Demo

这是一个面向比赛演示的移动端 H5 原型。产品层展示完整的个人审美助手，真实规则仍聚焦成人短袖 T 恤。

## 在线体验

部署完成后访问：<https://er18-w.github.io/ai-fit-lab-v1/>

当前版本提供：

1. 动物人格与本地身体档案；
2. 用户上传商品、合作商品双入口；
3. 短袖尺码、胸围松量、肩线与衣长关系计算；
4. AI 试穿异步流程模拟；
5. 衣服、裤子和鞋子搭配假数据；
6. 发型、发色、风格和体态情景等未来能力入口。

## 当前边界

- 网页使用本地数据，不上传照片；
- 尚未接入 MediaPipe、真实尺码表识别或付费试穿 API；
- 量体结果处于实验阶段，不提供裁缝级精度承诺；
- 缺少可靠胸围时，只输出候选尺码，不输出唯一精准推荐。

详细评审与执行计划见 [`V1_REVIEW_AND_EXECUTION_PLAN.md`](./V1_REVIEW_AND_EXECUTION_PLAN.md)。
