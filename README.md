# 自如 · 个人外形 Agent Demo

这是一个面向比赛演示的移动端 H5 原型。核心是“个人外形数据 + AI Agent”：身形、衣橱、穿搭、试穿、购物判断和外形探索共享同一份用户档案，但可以独立使用。尺码建议只是购物判断中的一项能力，不是产品中心。

## 在线体验

部署完成后访问：<https://er18-w.github.io/ai-fit-lab-v1/>

当前版本提供：

1. 分步骤外形档案：资料填写、拍摄说明、独立相机、照片比例报告、原图下载与二维形象导入；
2. 用户上传衣物、衣橱分类、搭配画布、拖动与保存穿搭；
3. 独立真人试穿流程模拟；
4. 上传商品、选择目标穿着效果，并用短袖成衣数据解释胸围松量、肩线、衣长和辅助尺码建议；
5. Agent 根据自然语言需求调用衣橱的交互演示；
6. 发型、面部与皮肤参考，以及彼此分离的身形档案和体态观察方向。

## 当前边界

- 网页使用本地数据，不上传照片；
- 已接入浏览器端 MediaPipe 姿态关键点作为实验拍摄教练；尚未接入真实衣物抠图、尺码表识别、Agent 服务或付费试穿 API；
- 二维基础形象暂时采用“下载原图 → Codex 人工生成 → 导回网页”的实验流程，尚未接自动生图后端；
- 量体结果处于实验阶段，不提供裁缝级精度承诺；
- 缺少可靠胸围时，只输出候选尺码，不输出唯一精准推荐。
